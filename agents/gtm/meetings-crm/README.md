# GTM · Meetings / CRM

Meeting prep, inbox drafts, CRM hygiene, and forecast briefs.

## Agents

- [10. Daily meeting prep](daily-meeting-prep.md) — Kristaletz: pull Salesforce, Gmail, Slack, Granola, Gong or fresh research; short skimmable phone-readable brief; optional custom deck for the day's calls.
- [11. Inbox scan + drafted replies](inbox-scan-drafted-replies.md) — Only threads that plausibly need a reply. Digest plus a proposed reply in the owner's voice. Never auto-send.
- [12. Follow-up drafts from call notes](follow-up-drafts-from-call-notes.md) — Detect external calls since last run. Draft To / Subject / body grounded in what was discussed, with concrete next steps.
- [13. CRM hygiene + next-best-action](crm-hygiene-next-best-action.md) — Ramp-style: read emails, call notes, transcripts; update contacts, stages, next steps, close dates, stakeholders; flag stale deals; recommend next action. Human approval on stage changes that move forecast.
- [14. Forecasting brief](forecasting-brief.md) — Nightly pipeline movement, forecast vs commit, stalled opps, inbound quality, call themes. Short brief on what is slipping and which accounts need exec attention. Cloudflare-style: draft, fact-check, then tone.
- [15. Pre-call one-pager / ROI / proposal](pre-call-one-pager-roi-proposal.md) — Opportunity context + pricing catalog + past deals + security answers + call notes → first draft, missing inputs flagged, versioned and logged.
