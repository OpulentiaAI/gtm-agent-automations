# Product

Scoping, PRDs, usage, experiments, beta, and the tickets that should become roadmap.

## Agents

- [Project Manager](project-manager.md) — Reads Slack and GitHub passively and keeps Linear current on its own. Anyone on the team can ask what the next highest priority is · uses `Slack, GitHub, Linear`.
- [Scoper](scoper.md) — Gives you a feasibility breakdown on every idea you send, having read the whole codebase · uses `GitHub, Slack`.
- [Beta Program Manager](beta-program-manager.md) — Researches each signup, reorders the waves, and runs the cohort once they are in · uses `cloud browser, Notion, email`.
- [PRD Writer](prd-writer.md) — Works from the actual customer calls, and quotes the actual customers · uses `Granola, Notion, Slack`.
- [Usage Auditor](usage-auditor.md) — Tells you monthly which shipped features nobody used, whether or not you asked · uses `Amplitude, Slack, Notion`.
- [Churn Analyst](churn-analyst.md) — Tags every survey answer into themes, watches while things ship, and monitors whether the answers change and churn moves · uses `Intercom, Google Sheets, Amplitude`.
- [FAQ Keeper](faq-keeper.md) — Builds it from the questions asked on sales calls and updates it before you wake up · uses `Gong, Notion, Slack`.
- [Competitor Teardown](competitor-teardown.md) — Signs up, uses the product, and writes what they do better · uses `cloud browser, Notion, Slack`.
- [Account Historian](account-historian.md) — “What did we promise this customer?” answered on one page from contracts, Slack, and the CRM · uses `Google Drive, Slack, HubSpot`.
- [Request Scorer](request-scorer.md) — Every feature request weighed against the revenue actually sitting behind it · uses `HubSpot, Linear, Slack`.
- [Beta Channel Host](beta-channel-host.md) — Answers users all day and escalates only what needs you · uses `Slack, Intercom`.
- [Experiment Designer](experiment-designer.md) — Writes the brief with the metric, the guardrail, and the stop condition filled in — then runs it · uses `Amplitude, Notion, Slack`.
- [Ticket Miner](ticket-miner.md) — Reads 90 days of support and finds the three fixes that kill the most volume · uses `Intercom, Linear, Slack`.
- [Demo Keeper](demo-keeper.md) — Sets up the demo environment before sales opens it · uses `cloud browser, Slack, Vercel`.
- [Activation Watchdog](activation-watchdog.md) — Tells you every week which onboarding step is quietly killing signups · uses `Amplitude, Slack, PostHog`.
