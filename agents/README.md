# Agents

Each Opulent agent is a markdown file with a paste-ready prompt. Start from a folder, then open the agent.

Setup for any file: [Stand up an Opulent agent](PLAYBOOK.md). Each of the 266 agent files also has its own playbook sections. The Work desk has a four-agent playbook in [work/README.md](work/README.md). GTM templates have a send-gated playbook in [gtm/README.md](gtm/README.md).

| Folder | What lives here |
| --- | --- |
| [work](work/README.md) | Inbox Manager, Calendar EA, Intel Scout, Bot Boss |
| [founders](founders/README.md) | Founder desk: EA, inbound, closer, burn, digest, chief of staff |
| [engineering](engineering/README.md) | Cloud coding, CI, prod, security, migrations |
| [product](product/README.md) | PM, scoper, PRD, usage, experiments, beta |
| [design](design/README.md) | Prototypes, library PRs, decks, design-system cops |
| [support](support/README.md) | Inbox, repro, billing, status, promises |
| [sales](sales/README.md) | SDR, outbound, trial, renewal, briefs |
| [marketing](marketing/README.md) | Voice, pages, paid, launch, truth cops |
| [data](data/README.md) | Analyst, reconcile, anomalies, tracking |
| [recruiting](recruiting/README.md) | Source, screen, schedule, onboard |
| [operations](operations/README.md) | Vendors, access, wiki, office, fleet |
| [finance](finance/README.md) | Invoices, burn, runway, rev rec, board |
| [legal](legal/README.md) | Review, redline, librarian, DSR, diligence |
| [personal](personal/README.md) | Cancels, claims, slots, groceries, family |
| [gtm](gtm/README.md) | GTM automations (outbound, inbound, CRM, creative, enablement) |

Copy the `Create an Opulent automation` prompt from any file into a new Opulent session.
