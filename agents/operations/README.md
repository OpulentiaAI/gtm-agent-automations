# Operations and IT

Vendors, access, the wiki, the office, and the fleet of other agents.

## Agents

- [Vendor Manager](vendor-manager.md) — Tracks every SaaS contract and renewal, with the usage data in your hands 30 days out · uses `Notion, email, Google Sheets`.
- [Access Manager](access-manager.md) — Opens the provisioning tickets the day someone joins, and confirms every account closed the day they leave · uses `Rippling, Linear, Slack`.
- [Ops Reporter](ops-reporter.md) — Monday numbers posted with the deltas and one line on each · uses `Postgres, Slack, Google Sheets`.
- [Drive Janitor](drive-janitor.md) — Rebuilds the mess into a wiki with owners and stale banners · uses `Google Drive, Notion, Slack`.
- [Noise Filter](noise-filter.md) — Cuts Slack down to what’s actionable, with the context and links attached · uses `Slack, Linear`.
- [Agent Fleet Manager](agent-fleet-manager.md) — Audits every agent for spend and kills the wasteful ones · uses `Slack, Postgres`.
- [Security Reviewer (Vendors)](vendor-security-reviewer.md) — Does the vendor questionnaire without anyone opening the PDF · uses `Google Drive, Notion, email`.
- [Offsite Planner](offsite-planner.md) — Venue, flights, dietary needs, and a schedule people follow · uses `cloud browser, Google Calendar, Slack`.
- [Access Reviewer](access-reviewer.md) — Weekly, flagging every permission nobody uses · uses `Rippling, AWS, Slack`.
- [Inbox Owner](inbox-owner.md) — Routes, answers, escalates, and summarizes once a day · uses `email, Slack, Linear`.
- [Wiki Keeper](wiki-keeper.md) — No two pages that contradict each other · uses `Notion, Slack`.
- [Compliance Chaser](compliance-chaser.md) — Overdue training handled so you never nag anyone again · uses `Rippling, Slack, email`.
- [Uptime Watcher](uptime-watcher.md) — Sees your own status page move so customers hear it from you first · uses `cloud browser, Slack, Datadog`.
- [Office Manager](office-manager.md) — Orders the snacks from Slack, through the DoorDash CLI and Amazon · uses `Slack, cloud browser`.
- [Events Manager](events-manager.md) — Maintains Luma, the waitlist, and markets it by dropping and listing it in relevant communities online · uses `cloud browser, Slack, email`.
