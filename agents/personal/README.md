# Personal

Cancels, claims, slots, groceries, family logistics, and the trip deck.

- [Slot Sniper](slot-sniper.md) — Watches passport, visa, or DMV for weeks and grabs one the moment you confirm · uses `cloud browser, text`.

- [Ticket Buyer](ticket-buyer.md) — In the second they drop · uses `cloud browser, text`.
